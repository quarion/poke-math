# Introduction

Math and Pokemon!
Side project made with Cursor and Sonnet 3.7. Almost 100% of the code is AI generated, with very slight manual tweaking

Live version: https://pokemath.quarion.dev/

## Infrastructure

Production infrastructure, deployment, cost controls, credential rotation, and public-release instructions are documented in [`infrastructure/README.md`](infrastructure/README.md). Do not download a Firebase service-account key for Cloud Run; production uses its attached service account and Application Default Credentials.

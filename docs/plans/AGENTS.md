# Agent instructions for implementation plans

- Treat Markdown files directly in this directory as active implementation plans.
- Do not read or rely on files in `completed/` by default. Consult them only when the task requires historical context, debugging, auditing, or project archaeology.
- Treat completed plans as historical evidence, not as authoritative documentation of the current system.
- When completing a plan, first promote durable knowledge into the relevant architecture document, requirement, or operational runbook. Then record the completion status and date and move the plan into `completed/`.
- Preserve archived plans. If a factual correction is needed, append a dated note instead of silently rewriting history.
